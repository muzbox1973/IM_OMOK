# IM_OMOK — 오목 · OMOK

사실적인 원목 바둑판 위에서 즐기는 웹 오목(고모쿠) 게임입니다.
설치 없이 `index.html` 하나로 동작하며, PC와 모바일 브라우저를 모두 지원합니다.

## 주요 기능

- **AI 대전** — 초급 · 중급 · 고급 세 단계의 AI와 대국. 흑(선공)·백 선택 가능.
- **2인 대전(PvP)** — 한 기기에서 두 사람이 번갈아 착수.
- **오목 교실** — 기초(Lv.1) → 중급(Lv.2) → 고급(Lv.3) 과정과 용어 사전.
  승리 조건과 판 읽기부터 활삼·멍삼, 사삼(4·3), 쌍삼, 연속 공격(VCF), 포석까지 그림으로 설명합니다.
- **대국 편의** — 무르기(AI 모드에서는 사람 차례가 되도록 자동 조정), 다시 시작, 착수 미리보기(호버/터치 조준), 돌 두는 소리(WebAudio 합성), 기록 패널.
- **모바일 UI** — 손가락으로 조준한 뒤 떼면 착수되는 오착 방지 입력, 화면 폭에 맞춘 반응형 레이아웃.

## 규칙

- 15×15 바둑판, 흑이 먼저 둡니다.
- 가로·세로·대각선 어느 방향이든 같은 색 돌 다섯 개를 이으면 승리합니다.
- 판이 가득 차면 무승부입니다.
- 금수(삼삼·사사·장목)는 적용하지 않는 자유 오목입니다.

## AI 난이도

| 단계 | 방식 |
|---|---|
| 초급 | 1수 평가. 즉승과 상대의 5 완성 차단은 알지만, 열린3 이하의 위협을 자주 놓치고 상위 후보 중 무작위로 두는 등 초보자처럼 실수합니다. |
| 중급 | 공격·수비를 충실히 반영한 1수 평가. 열린3과 4는 빠짐없이 막습니다. |
| 고급 | 2수 앞 미니맥스에 연속 4 공격(VCF) 탐색을 더했습니다. 사삼·쌍삼·쌍사 같은 이중 위협을 만들고, 상대의 연속 공격을 허용하는 수는 피합니다. |

평가 함수는 연속 돌뿐 아니라 `O O _ O O` 같은 띈 모양도 인식합니다.
레벨 간 자체 대국(40판 기준)에서 중급이 초급을 70:9, 고급이 초급을 78:1, 고급이 중급을 49:18로 이깁니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도의 서버나 빌드 과정이 필요 없습니다.
글꼴(Gowun Batang, Cormorant Garamond)은 Google Fonts에서 불러오며, 오프라인에서는 기본 글꼴로 표시됩니다.

## 기술

- 순수 HTML / CSS / JavaScript 단일 파일. 외부 라이브러리 없음.
- 바둑판은 Canvas로 절차적 나뭇결을 그려 만들고, 돌·승리선은 DOM 요소로 배치합니다.
- 배포용 `index.html`의 스크립트는 난독화되어 있습니다.
